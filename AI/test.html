비문학: 기술 설명 지문 분석

문제 1

[난이도 중 / 출처: Parallel Softmax 과제 보고서]
다음은 GPU를 활용한 LoRA 연산의 최적화 과정에 대한 설명 일부이다. 이를 읽고 물음에 답하시오.

GPU를 활용하여 LoRA의 행렬 연산을 최적화하기 위해 다양한 기법이 적용되었다. 먼저 data parallelism을 blockId와 threadId를 이용해 구현하여 여러 데이터에 동시에 접근, 계산할 수 있게 하였고, CPU와 GPU의 메모리 접근 방식 차이에 따라 행렬의 전치(transpose)를 적용하였다. 작은 캐시 크기로 인한 효율 저하를 방지하기 위해 타일링(tiling) 기법도 적용하였다. 타일 크기를 실험적으로 8, 16, 32로 비교한 결과 16이 가장 효율적이었으며, 루프 언롤링, syncthread로 안전성 확보, restrict 키워드로 빠른 memory 계층 사용 등 여러 방식으로 최적화하였다.

  • ① 타일링 기법은 캐시의 크기에 맞추어 데이터를 불러와, 캐시 미스를 최소화하려는 것이다.
  • ② LoRA 연산의 대부분은 matrix add 연산에서 수행된다.
  • ③ blockId와 threadId를 활용한 병렬화는 여러 연산을 순차적으로 처리하는 방식에 해당한다.
  • ④ restrict 키워드는 연산의 병렬성이 높아지면 꼭 사용하지 않아도 된다.

해설지

문제 1 해설
①은 타일링(tiling) 기법의 설명으로, 캐시 미스를 줄이고자 캐시 용량에 맞게 데이터를 활용하는 것이 옳다.
②는 LoRA 연산의 대부분이 matrix multiplication에 해당하므로 틀렸다.
③은 여러 연산을 병렬적으로 처리하는 것이므로 '순차적'이란 설명이 맞지 않다.
④는 restrict 키워드를 통해 빠른 메모리 계층(SRAM 등)을 사용하므로, 연산의 병렬성과 관계없이 사용하는 것이 좋다.
